# Task 4.3: Мини-игры — Велосипед и Поиск предметов (Mini-games: Cycling & Hidden Objects)

## Цель
Реализовать две ключевые мини-игры, разнообразящие геймплей: симулятор езды на велосипеде с физикой и механикой выносливости, а также классическая игра "Поиск предметов" (Hidden Object Game) в статичных сценах.

---

## Часть 1: Мини-игра "Велосипед" (Cycling Mini-game)

### 1.1 Концепция
Игрок управляет велосипедистом, перемещаясь между локациями Castelvento. Геймплей сочетает элементы аркадного гонщика и симулятора путешествия.

### 1.2 Физика и управление

#### Параметры движения
```typescript
interface BikePhysics {
  speed: number; // Текущая скорость (0-30 км/ч)
  maxSpeed: number; // Максимальная скорость (зависит от апгрейдов)
  acceleration: number; // Скорость разгона
  friction: number; // Сопротивление качению (асфальт vs грунт)
  stamina: number; // Текущая выносливость (0-100)
  staminaDrain: number; // Расход выносливости при педалировании
  staminaRegen: number; // Восстановление при спуске/инерции
}
```

#### Управление (Input)
*   **PC**: 
    *   `W` / `Up Arrow` / Удержание ЛКМ: Педалирование (ускорение).
    *   `S` / `Down Arrow`: Торможение.
    *   `A` / `D` / `Left` / `Right`: Поворот (смещение по дороге).
    *   `Space`: Рывок (Dash) — тратит много выносливости.
*   **Mobile**: 
    *   Виртуальные педали (тап/удержание).
    *   Наклон устройства (гироскоп) для управления положением на дороге.

#### Реализация физики (Arcade-style)
Движение не использует полноценный физический движок (типа Cannon.js), а базируется на кинематических формулах для простоты и контроля:
```typescript
function updateBike(deltaTime: number) {
  if (isPedaling && stamina > 0) {
    speed += acceleration * deltaTime;
    stamina -= staminaDrain * deltaTime;
  } else {
    // Инерция и трение
    speed -= friction * deltaTime;
    if (speed < 0) speed = 0;
    stamina = Math.min(stamina + staminaRegen * deltaTime, 100);
  }
  
  // Ограничение скорости
  speed = Math.min(speed, maxSpeed);
  
  // Обновление позиции вдоль сплайна маршрута
  distanceTraveled += speed * deltaTime;
  position = getSplinePoint(routeSpline, distanceTraveled);
}
```

### 1.3 Трасса и Камера

#### Маршрут (Spline System)
*   Дорога задается кривой Безье (Catmull-Rom spline).
*   Игрок движется строго вдоль сплайна, но может смещаться влево/вправо в пределах ширины дороги (для уклонения от препятствий).
*   **Секции трассы**: Каждая секция имеет тип покрытия (`asphalt`, `gravel`, `sand`), влияющий на `friction`.

#### Камера (Follow Camera)
*   Позиция камеры: сзади и чуть выше велосипедиста (Third-person view).
*   **Динамика**:
    *   При ускорении камера немного отдаляется и опускается (эффект скорости).
    *   При повороте камера плавно поворачивается вместе с игроком (`lerp` rotation).
    *   FOV меняется в зависимости от скорости (Speed-based FOV).

### 1.4 Препятствия и события

#### Типы препятствий
1.  **Статические**: Камни, ямы, лужи. Столкновение снижает скорость и выносливость.
2.  **Динамические**: Прохожие, животные, машины (на границах города). Требуют своевременного маневра.
3.  **Бонусы**: 
    *   `EnergyDrink`: Восстанавливает выносливость.
    *   `Postcard`: Коллекционный предмет (увеличивает счет).
    *   `Tailwind`: Попутный ветер (временный буст скорости).

#### Система столкновений
Упрощенная AABB или Sphere collision проверка между bounding box игрока и препятствиями.
```typescript
function checkCollisions() {
  obstacles.forEach(obs => {
    if (distance(player.position, obs.position) < threshold) {
      triggerCollision(obs.type);
    }
  });
}
```

### 1.5 UI Велосипеда
*   **Спидометр**: Анимированный циферблат в винтажном стиле.
*   **Шкала выносливости**: Полоска в виде старой батарейки или шкалы термометра. Меняет цвет (Зеленый -> Желтый -> Красный).
*   **Мини-карта**: Схема маршрута с текущей позицией.
*   **Счетчик открыток**: Количество собранных предметов за заезд.

## Часть 2: Мини-игра "Поиск предметов" (Hidden Object Game)

### 2.1 Концепция
Игрок оказывается в статичной, детально прорисованной сцене (комната, площадь, пляж). Необходимо найти список указанных предметов, спрятанных в окружении.

### 2.2 Архитектура сцены

#### Структура данных уровня
```typescript
interface HiddenObjectLevel {
  id: string;
  backgroundUrl: string; // Высокодетализированный спрайт фона
  timeLimit?: number; // Таймер в секундах (null для свободного режима)
  targetItems: TargetItem[];
  hints: number; // Количество доступных подсказок
}

interface TargetItem {
  id: string;
  name: string; // Название для списка
  iconName: string; // Иконка в списке поиска
  hitBox: { x: number; y: number; width: number; height: number }; // Координаты зоны клика (% от экрана)
  found: boolean;
  animation?: string; // Анимация при нахождении (пульсация, исчезновение)
}
```

### 2.3 Механика поиска

#### Зоны клика (Hitboxes)
*   Предметы не являются отдельными спрайтами, а "вшиты" в фон.
*   Над каждым предметом размещается невидимый интерактивный прямоугольник (`hitBox`).
*   **Размер хитбокса**: Должен быть достаточно большим для комфортного клика на мобильных устройствах (минимум 44x44 пикселя), даже если сам предмет маленький.

#### Взаимодействие
1.  **Наведение**: При наведении мыши на правильную зону курсор меняется на лупу, предмет слегка подсвечивается (glow effect).
2.  **Клик**: 
    *   Если предмет найден: Проигрывается анимация (предмет "выпрыгивает" или растворяется), звук "ding", элемент в списке зачеркивается.
    *   Если клик мимо: Штраф времени (если есть таймер) или визуальный эффект "ошибки" (экран краснеет).

#### Список предметов (UI)
*   Расположение: Низ экрана или боковая панель.
*   Отображение: Силуэты или иконки с названиями.
*   Найденные предметы: Становятся цветными и зачеркиваются.

### 2.4 Подсказки (Hint System)
*   **Кнопка "Подсказка"**: Иконка лампочки.
*   **Логика**: При нажатии система ищет ближайший еще не найденный предмет и проигрывает стрелку-указатель или кратковременно подсвечивает его зону.
*   **Ограничение**: Перезарядка подсказки (cooldown) 10-15 секунд или лимит использований на уровень.

### 2.5 Условия победы и поражения
*   **Победа**: Все предметы найдены. Начисление звезд (1-3) в зависимости от времени. Награда переходит в основной инвентарь.
*   **Поражение** (если есть таймер): Время вышло. Предложение попробовать снова или использовать внутриигровую валюту для добавления времени.

## 3. Интеграция и прогрессия

### 3.1 Велосипед в основном геймплее
*   Используется для быстрого перемещения между удаленными точками карты.
*   Открывает новые диалоги с NPC, встреченными по пути.
*   Достижения: "Проехать 10 км без падений", "Найти все скрытые открытки".

### 3.2 Поиск предметов в сюжете
*   Встроен в основные сцены как способ найти ключевые улики.
*   Пример: "Найди 5 инструментов в сарае, чтобы починить велосипед".
*   Сложность растет: больше предметов, меньше размеры хитбоксов, отвлекающие факторы (движущиеся объекты на фоне).
