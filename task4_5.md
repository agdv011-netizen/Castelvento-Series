# Task 4.5: Аудио-движок и динамическое микширование (Audio Engine)

## Цель
Создать продвинутую систему управления аудио, обеспечивающую атмосферное погружение через динамическое микширование, пространственный звук (3D Audio) и адаптивную музыку, реагирующую на события игры.

## 1. Архитектура аудио-системы

### 1.1. Компоненты системы
1.  **AudioContext Manager:** Обертка над Web Audio API для управления глобальным контекстом.
2.  **SoundChannels:** Логическое разделение потоков:
    -   `Master`: Общая громкость.
    -   `Music`: Фоновая музыка (BGM).
    -   `SFX`: Звуковые эффекты (шаги, клики, UI).
    -   `Ambience`: Окружающие звуки (ветер, море, птицы).
    -   `Voice`: Голосовые дорожки (если будут).
3.  **SpatialAudioProcessor:** Модуль для расчета панорамирования (PannerNode) и затухания по расстоянию.
4.  **AdaptiveMusicController:** Логика кроссфейда и переключения музыкальных треков в зависимости от состояния сцены.

## 2. Реализация核心 функционала

### 2.1. Класс AudioManager
Файл: `client/services/AudioManager.ts`

**Методы:**
-   `initialize()`: Создание AudioContext, загрузка конфигов.
-   `play(soundId: string, options?: PlayOptions)`: Запуск звука.
-   `stop(soundId: string)`: Остановка конкретного звука или группы.
-   `setVolume(channel: string, value: number)`: Регулировка громкости канала.
-   `setMix(mixName: string)`: Плавный переход к предустановленному миксу (например, при входе в диалог).
-   `updatePosition(listenerPos: Vector3, soundPos: Vector3)`: Обновление позиций для 3D звука (вызывается каждый кадр для активных источников).
-   `pauseAll() / resumeAll()`: Управление при потере фокуса окном.

### 2.2. Пространственный звук (3D Audio)
Использование `PannerNode` из Web Audio API.
-   **Listener:** Виртуальный слушатель, привязанный к камере игрока.
-   **Source:** Привязка к игровым объектам (велосипед, NPC, источники шума).
-   **Параметры затухания:**
    -   `rolloffFactor`: Скорость затухания.
    -   `refDistance`: Расстояние, на котором звук слышен на полной громкости.
    -   `maxDistance`: Расстояние, после которого звук не слышен.
-   **Доплеровский эффект:** Опционально для быстрых объектов (велосипед, машины).

### 2.3. Адаптивная музыка
Реализация через систему слоев или кроссфейд:
1.  **Сценарные триггеры:** Скрипт сцены отправляет событие `AUDIO_CHANGE_STATE` (напр. "tension_rising").
2.  **Переход:** Менеджер плавно (fade-in/fade-out, 1-2 сек) меняет трек с "calm_exploration" на "mystery_investigation".
3.  **Вертикальное микширование (опционально):** Если музыка записана слоями (барабаны, струнные, мелодия), включение/выключение слоев в реальном времени в зависимости от интенсивности действия.

## 3. Интеграция с игровым циклом

-   **Game Loop:** Вызов `audioManager.update()` каждый кадр для обновления позиций 3D звуков относительно камеры.
-   **Scene Transition:**
    -   При уходе со сцены: Fade-out всех звуков сцены.
    -   При загрузке сцены: Запуск фоновой музыки и амбиенса с плавным нарастанием.
-   **UI Interactions:** Звуки кликов, ховера, открытия модалок (короткие SFX без задержки).

## 4. UI Настроек Аудио

Экран настроек должен содержать:
-   Ползунки для каждого канала (Master, Music, SFX, Ambience, Voice).
-   Переключатель "Mono/Stereo" (для доступности).
-   Индикатор активности микрофона (если планируется голосовой ввод в будущем).
-   Кнопка "Тест звука" (проигрывает короткий семпл).

## 5. Обработка ошибок и Edge Cases

-   **Autoplay Policy:** Браузеры блокируют автовоспроизведение звука до первого взаимодействия пользователя.
    -   *Решение:* Инициализировать AudioContext в "suspend" состоянии. Resume() вызывать при первом клике/таче в любом месте игры (глобальный listener). Показать заглушку "Click to Start" если нужно.
-   **Потеря контекста:** Обработка событий `interrupted` (звонок на мобильном) -> пауза, `resumed` -> возобновление.
-   **Отсутствие файлов:** Graceful degradation (игра продолжается без звука, логирование ошибки).
-   **Мобильные устройства:** Ограничение на количество одновременных полифонических каналов (iOS Safari). Приоритизация важных звуков (голос > музыка > фон).

## 7. Пример использования в коде сцены

```typescript
// В скрипте сцены
scene.onEnter(() => {
  audioManager.play('bgm_forest_day');
  audioManager.play('ambience_birds', { loop: true, position: {x: 10, y: 0, z: -5} });
});

scene.onEvent('player_approaches_danger', () => {
  audioManager.setMix('tension'); // Плавно меняет эквалайзер и громкость
});

scene.onInteraction('bike_bell', () => {
  // Проигрываем звук звонка в позиции велосипеда
  audioManager.play('sfx_bike_bell', { 
    position: player.position, 
    relativeTo: 'camera' 
  });
});
```

## 8. Требования к ассетам

-   **Форматы:** `.ogg` для музыки и длинных лупов (лучшее сжатие), `.mp3` или `.wav` для коротких SFX (быстрая декодировка).
-   **Битрейт:** Музыка ~128kbps, SFX ~192kbps или выше для четкости.
-   **Название файлов:** Строгая нотация (`type_category_name_variant.ext`), например: `sfx_ui_click_01.wav`, `mus_bgm_chapter1_loop.ogg`.
