# Task 4.1: Система диалогов и ветвления (Dialogue Engine & Branching System)

## Цель
Реализовать универсальный движок диалогов, поддерживающий нелинейные сценарии, условия, переменные состояния и интеграцию с визуальными элементами (портреты, анимации, фон).

---

## 1. Архитектура данных

### 1.1 Структура JSON-сценария
Файлы сценариев хранятся в `client/src/data/dialogues/chapter1/`.
Каждый файл соответствует одной локации или сюжетному узлу.

```json
{
  "id": "scene_001_town_square",
  "version": "1.0",
  "nodes": [
    {
      "id": "start",
      "speaker": "narrator",
      "text": "Утро в Кастельвенто начинается с запаха моря...",
      "portrait": null,
      "mood": "neutral",
      "background": "town_square_morning",
      "music": "track_01_morning_theme",
      "next": "meet_mario"
    },
    {
      "id": "meet_mario",
      "speaker": "mario",
      "text": "Buongiorno! Ты уже видел новую открытку?",
      "portrait": "mario_happy",
      "mood": "happy",
      "choices": [
        {
          "text": "Да, она прекрасна.",
          "next": "response_positive",
          "effect": { "flag": "liked_postcard", "value": true }
        },
        {
          "text": "Еще нет, только проснулся.",
          "next": "response_neutral",
          "condition": { "flag": "met_before", "operator": "!=", "value": true }
        }
      ]
    }
  ]
}
```

### 1.2 Типы узлов (Node Types)
1.  **Standard**: Обычная реплика. Переход по полю `next`.
2.  **Choice**: Узел выбора. Содержит массив `choices`.
3.  **Action**: Узел без текста, выполняющий скрипт (изменение флага, запуск анимации, переход сцены).
4.  **Random**: Случайный выбор следующего узла из списка (для вариативности реплик прохожих).

### 1.3 Условия (Conditions)
Поддерживаемые операторы: `==`, `!=`, `>`, `<`, `>=`, `<=`, `has_item`, `visited_location`.
Пример: `"condition": { "flag": "chapter1_completed", "operator": "==", "value": true }`

## 2. Реализация движка (TypeScript/React)

### 2.1 Интерфейсы (types.ts)
```typescript
export interface DialogueNode {
  id: string;
  speaker?: string;
  text: string;
  portrait?: string;
  mood?: 'neutral' | 'happy' | 'sad' | 'angry' | 'surprised';
  background?: string;
  music?: string;
  next?: string;
  choices?: Choice[];
  action?: DialogueAction;
  condition?: Condition;
}

export interface Choice {
  text: string;
  next: string;
  effect?: StateEffect;
  condition?: Condition;
  locked?: boolean; // Визуальный замок, если условие не выполнено
}

export interface DialogueState {
  currentNodeId: string | null;
  history: string[]; // История пройденных узлов для отката
  flags: Record<string, any>; // Глобальные переменные сессии
  inventory: string[]; // Текущие предметы (для проверок has_item)
  isTyping: boolean;
  displayedText: string;
}
```

### 2.2 Хук использования (useDialogueEngine.ts)
Логика интерпретатора:
1.  **Инициализация**: Загрузка JSON, установка `currentNodeId` на 'start'.
2.  **Обработка текста**: Эффект печатной машинки (`typewriter`). Скорость: 30мс/символ. Пропуск по клику.
3.  **Переходы**:
    *   Если есть `choices`: приостановить автоматический переход, ждать ввода пользователя.
    *   Если есть `action`: выполнить перед отображением текста.
    *   Проверка `condition`: если ложь, искать альтернативный путь или завершать ветку.
4.  **Управление состоянием**: Сохранение истории для функции "Назад" (если реализована в UI).

### 2.3 Компоненты UI

#### `DialogueBox.tsx`
*   Расположение: Низ экрана (height: 25vh).
*   Стиль: Текстура старой бумаги, винтажная рамка.
*   Анимация появления: `fade-in-up` (0.3s).
*   Содержимое:
    *   Имя говорящего (шрифт: рукописный, цвет: темно-синий).
    *   Текст реплики (шрифт: печатная машинка, размер адаптивный).
    *   Индикатор продолжения (стрелочка вниз, мигает, если текст полностью показан).

#### `PortraitContainer.tsx`
*   Расположение: Слева или справа от диалогового окна (зависит от позиции персонажа).
*   Анимация смены настроения: `cross-fade` + легкое смещение (`translateY`).
*   Поддержка "Live2D" эффектов (покачивание при дыхании) через CSS keyframes.

#### `ChoiceMenu.tsx`
*   Появляется поверх затемненного фона при наличии выборов.
*   Список кнопок с текстом вариантов.
*   Hover-эффект: подсветка варианта, легкий зум.
*   Locked-варианты: полупрозрачные, с иконкой замка, некликабельные.

## 3. Интеграция с игрой

### 3.1 Триггеры начала диалога
*   **Коллизия**: Игрок подходит к NPC (расстояние < 2м) + нажатие клавиши взаимодействия ('E' / Tap).
*   **Скрипт сцены**: Автоматический запуск диалога при переходе в определенную сцену (cutscene).

### 3.2 Управление камерой во время диалога
*   При начале диалога камера плавно (`lerp`, duration 1s) фокусируется на говорящем.
*   Если говорящих несколько (спор), камера переключается между ними при смене реплики.
*   Поле зрения (FOV): небольшое увеличение (zoom in) для драматических моментов.

### 3.3 Аудио-сопровождение
*   **Голос**: Опциональное воспроизведение звуковых файлов (phoneme sync пока не требуется, просто озвучка реплики).
*   **Музыка**: Плавное затухание (fade-out 2s) текущей темы и включение новой, указанной в узле.
*   **SFX**: Звук печатной машинки при выводе текста (можно отключить в настройках).

## 4. Валидация и отладка

### 4.1 Валидатор сценариев
Скрипт (Node.js), проверяющий JSON перед загрузкой:
*   Отсутствие битых ссылок (`next` указывает на несуществующий ID).
*   Циклические зависимости (бесконечные циклы без выхода).
*   Отсутствие условий для обязательных переменных.

### 4.2 Режим отладки (Dev Mode)
*   Отображение текущего ID узла на экране.
*   Кнопки "Skip Node", "Force Choice", "Print Flags".
*   Логирование всех изменений флагов в консоль.
